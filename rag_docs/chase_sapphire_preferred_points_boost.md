# Chase Sapphire Preferred — Points Boost

## Benefit summary
Sapphire Preferred cardmembers can receive enhanced point value on select flights and top-booked hotels through Chase Travel when a Points Boost offer is available.

## Dynamic nature
- Points Boost is not available on every booking.
- Eligible offers are shown in Chase Travel search results.
- Offers rotate and can change.
- Current published maximum for Sapphire Preferred is up to 1.5x value on eligible offers.

## How RewardPilot should use this
Never assume every Chase Travel redemption receives the maximum Points Boost value. If no live Points Boost information is available, use the baseline redemption rule and label Points Boost as an unverified opportunity.

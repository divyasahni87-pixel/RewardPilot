# Chase Sapphire Reserve — Points Boost

## Benefit summary
Sapphire Reserve cardmembers can receive enhanced value on select Chase Travel hotel and flight bookings through Points Boost.

## Dynamic nature
- Points Boost applies only to marked eligible inventory.
- Offers are promotional and refreshed periodically.
- Current published maximum is up to 2x value on eligible Reserve offers.

## How RewardPilot should use this
Never convert a cash fare using 2 cents per point unless that specific booking is confirmed as a qualifying Points Boost offer.
